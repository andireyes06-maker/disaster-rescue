# I-Report response workspace visual implementation

Approved scope: owner requests UI changes across the web, explicitly incident details and Assign team. Work uncommitted; preserve all current API/permission/workflow contracts and concurrent changes.

Direction: a civic response workspace with a clear geographic and operational identity. Keep Geist, the exact I-Report mark, violet #6D28D9 and harbor #241747. Add semantic field blue #1D4ED8, response teal #0F766E, attention amber #92400E and light canvas #EEF1F8. Category colors follow incident types; state colors carry meaning alongside text/icons.

Layout: compact dark page identity bands; calm reading areas; incident facts beside the next action, actual geographic location and evidence; a sequenced progress track. Assignment is a wider, structured selection workspace with clear team identity, proximity and selection feedback. Keep desktop controls compact and phone targets generous.

First pass: shared tokens/layout/modal family; incident workspace; assignment cards/keyboard behavior; chart colors; recovery/handoff/empty states; public section rhythm and directory identity. Second pass: rendered critique at desktop/phone, meaningful regression checks and handoff.

Avoid: decoration-only gradients, fake live data, random colored cards, filler photos, changing account permissions or submitting real records. Do not resurrect removed resident/monitor routes or password-recovery flows another session intentionally changed. Existing map tile provider is retained. All browser mutations use local fictional fixtures or clearly disclosed mocks.
